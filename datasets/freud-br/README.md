## Sobre os TEXTOS INTEGRAIS de Freud (direito autoral)

- A **obra original** de Freud (alemao, falecido 1939) e **dominio publico**.
- **Toda traducao** tem direito autoral proprio (do tradutor). As traducoes
  brasileiras (Imago, Companhia das Letras, L&PM) seguem **protegidas** — nao
  existe Freud completo em PT em dominio publico.
- Vias **legais** para os textos integrais: traducao espanhola de **Luis
  Lopez-Ballesteros** (tradutor +70 anos, falecido 1938 -> dominio publico),
  originais em **alemao** (DP) ou traducoes inglesas DP (Brill/Gutenberg). Para
  PT-BR, traduzir por maquina uma fonte DP. **Nunca** ePubs piratas (Scribd) nem
  edicoes com aparato protegido (Numhauser/Biblioteca Nueva).
